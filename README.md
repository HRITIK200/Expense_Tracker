## 📘 Project Overview
The **Expense Tracker App** is a responsive, feature-rich web application that helps users track their daily income and expenses efficiently.  
Built using **HTML5, CSS3, and modern JavaScript**, it allows users to add, edit (via custom modal), delete, filter, and sort transactions.  
Data is stored securely in the browser’s **localStorage**, ensuring privacy and persistence.  
The app features dynamic interactive charts via **Chart.js** (Category Breakdown & Cashflow Comparison), monthly budget tracking, CSV/JSON export, and seamless Light/Dark mode.

---

## 🎯 Objectives
- To create an interactive and user-friendly financial tracker.  
- To implement **CRUD operations** using JavaScript.  
- To use **localStorage** for persistent data management.  
- To display **real-time summaries and charts** for better analysis.  
- To design a clean, professional, and responsive user interface.

## 🧠 Features
✅ **CRUD Operations**: Add, Edit (via sleek modal dialog), and Delete Transactions  
✅ **Dark & Light Mode**: Seamless theme switching with user preference saved in Local Storage  
✅ **Monthly Budget Planner**: Set a monthly budget goal with an automated visual progress bar and threshold alerts  
✅ **Interactive Analytics (Chart.js)**: Toggle between **Expense Category Doughnut** and **Cashflow Bar Chart**  
✅ **Multi-Criteria Filtering & Sorting**: Filter by Category, Type (Income/Expense), Time Range (Today, Week, Month, Year), and sort by Date or Amount  
✅ **Quick Suggestion Chips**: Fast 1-click description and category entry  
✅ **Export & Import**: Export directly to **CSV** (for Excel/Google Sheets) and **JSON**, with JSON restore support  
✅ **Toast Notification System**: Modern, non-intrusive feedback toasts replacing browser alerts  
✅ **Demo Data Loader**: 1-click sample data generator for instant testing  
✅ **100% Privacy & Offline Ready**: All data remains secure in browser `localStorage`  
✅ **Universal Device Compatibility**: Optimized for mobile phones (touch targets ≥44px), tablets, laptops, and ultra-wide screens

## ▶️ How to run the project

- **Open directly:** double-click `index.html` to open it in your browser (no build step required).

- **Recommended (VS Code):** install the **Live Server** extension, then right-click `index.html` → _Open with Live Server_.

- **Using a simple server:**
  - Python: `python -m http.server 8000` → open http://localhost:8000
  - Node: `npx http-server` → open the printed URL (or install `http-server` globally and run `http-server`)
